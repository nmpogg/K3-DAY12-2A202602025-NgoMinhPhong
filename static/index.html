Hạ Tầng Cloud & Deployment

Từ mã nguồn chạy cục bộ (localhost) tiến lên hệ thống chuẩn Production trên Cloud với đầy đủ bảo mật và CI/CD.

1. 12-Factor App

Quản lý cấu hình linh hoạt thông qua biến môi trường (Environment Variables). Không bao giờ hardcode mật khẩu hay API Key vào source code.

2. Multi-stage Docker

Đóng gói ứng dụng vào container với kỹ thuật Multi-stage build để giảm thiểu dung lượng Image (dưới 500MB) và tăng tính bảo mật.

3. API Security

Bảo vệ API khỏi các cuộc tấn công DDoS với Rate Limiter thuật toán Sliding Window và hệ thống Cost Guard kiểm soát ngân sách LLM.

4. Reliability

Thiết kế hệ thống phi trạng thái (Stateless) kết hợp với Liveness & Readiness Probes giúp tự động phát hiện lỗi và phục hồi hệ thống.

5. Cloud Deploy

Đưa hệ thống lên môi trường đám mây thực tế (Render/Railway), xử lý Graceful Shutdown để không làm gián đoạn request của người dùng khi update.

BONUS: CI/CD Pipeline

Tự động hóa toàn bộ quy trình kiểm thử và triển khai bằng GitHub Actions. Tự động Deploy lên server khi code vượt qua mọi bài test.

.github/workflows/ci.yml
# Tự động hóa Pipeline từ lúc Push code đến lúc lên Production name: CI/CD Pipeline on: push: branches: ["main"] jobs: test: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - run: pytest deploy: needs: test runs-on: ubuntu-latest steps: - run: curl -X POST ${{ secrets.RENDER_DEPLOY_HOOK }}
